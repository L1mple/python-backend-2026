=== non_repeatable_read.py ===

--- isolation = READ_COMMITTED ---
T1: first read value = 100
T2: UPDATE value = 200 and COMMIT
T1: second read value = 200
>>> NON-REPEATABLE READ reproduced (values differ)

--- isolation = REPEATABLE_READ ---
T1: first read value = 100
T2: UPDATE value = 200 and COMMIT
T1: second read value = 100
>>> non-repeatable read is GONE (values are the same)
