
# HW3

Docker и мониторинг для Shop API из второй домашней работы.

## Запуск

Нужны Docker и Docker Compose. Из папки `hw3`:

```sh
docker compose up --build -d

```

- API и Swagger: <http://localhost:8080/docs>
- Метрики приложения: <http://localhost:8080/metrics>
- Prometheus: <http://localhost:9091>
- Grafana: <http://localhost:3000>, логин и начальный пароль `admin`.

При первом входе Grafana предложит сменить пароль. Источник данных Prometheus
и два дашборда в папке Shop API создаются автоматически:

- Requests: частота запросов, HTTP-статусы и доля ошибок.
- Performance: время ответа, доступность, CPU и память процесса приложения.

Prometheus собирает метрики каждые 10 секунд. Чтобы увидеть графики частоты
запросов и времени ответа, отправьте несколько запросов через Swagger и
подождите два-три интервала сбора. Ошибки 4xx можно получить запросом
несуществующего товара или отправкой некорректного тела запроса.

## Остановка

```sh
docker compose down

```

Данные Prometheus и Grafana сохраняются в Docker volumes. Данные магазина
и комнаты чата хранятся в памяти приложения и сбрасываются при его перезапуске.
